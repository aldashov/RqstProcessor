# Task Processor Service

Асинхронный бэкенд-сервис на Go 1.27+ с PostgreSQL (`pgxpool`), структурированным логированием (`log/slog`) и управлением через Makefile.

## Быстрый запуск (Makefile)

* **`make up`** — запуск всей среды в фоновом режиме через Docker Compose.
* **`make logs`** — просмотр логов приложения в реальном времени.
* **`make stop`** — мягкая остановка (Graceful Shutdown: веб-сервер прекращает прием запросов, воркеры завершают активные задачи) [FACT: система].
* **`make down`** — полная остановка с очисткой контейнеров и сетей.

## Изолированное тестирование

* **`make test`** — запуск тестов в изолированном Docker-окружении (`postgres_test`, миграции, флаг `-race`).
* **`make test-local`** — локальный запуск тестов (требует установленного Go).

## REST API (Порт 8081)

Поддерживаются эндпоинты `/tasks`:
* **POST `/tasks`** — создание задачи (`{"title":"..."}`).
* **GET `/tasks`** — список всех задач.
* **GET `/tasks/{id}`** — получение задачи по ID.
* **DELETE `/tasks/{id}`** — удаление задачи (запрещено для статуса `processing`) -> ответ: `{"result":"OK"}`.
* **GET `/health`** — проверка здоровья сервиса и связи с БД.
