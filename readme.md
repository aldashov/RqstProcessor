# Task Processor Service

Асинхронный бэкенд-сервис на Go 1.27+ с PostgreSQL (**GORM** — `gorm.io/gorm`, `gorm.io/driver/postgres`), структурированным логированием (`log/slog`) и управлением через Makefile.

## Быстрый запуск (Makefile)

* **`make up`** — запуск всей среды в фоновом режиме через Docker Compose.
* **`make logs`** — просмотр логов приложения в реальном времени.
* **`make stop`** — мягкая остановка (Graceful Shutdown: веб-сервер прекращает прием запросов, воркеры завершают активные задачи).
* **`make down`** — полная остановка с очисткой контейнеров и сетей.

## Изолированное тестирование

* **`make test`** — запуск тестов в изолированном Docker-окружении (`postgres_test`, миграции, флаг `-race`).
* **`make test-local`** — локальный запуск тестов (требует установленного Go).

## REST API (Порт 8081)

| Метод    | Путь          | Тело запроса          | Коды ответа и формат                                                                 |
| :---     | :---          | :---                  | :---                                                                                 |
| `POST`   | `/tasks`      | `{"title": "string"}` | `201`/`200` — созданная задача (`status: "processing"`); `400` — пустой `title`      |
| `GET`    | `/tasks`      | —                     | `200` — JSON-массив всех задач                                                       |
| `GET`    | `/tasks/{id}` | —                     | `200` — объект задачи (`processing` -> `done` через 7 с); `404` — не найдена         |
| `DELETE` | `/tasks/{id}` | —                     | `200` — `{"result": "OK"}`; `403`/`409` — запрещено для задач в статусе `processing` |
| `GET`    | `/health`     | —                     | `200` — сервис и PostgreSQL доступны; `503` — ошибка `Ping` к БД                     |

### Быстрая проверка

```bash
# Проверка доступности сервиса и БД
curl -i http://localhost:8081/health

# Создание фоновой задачи
curl -i -X POST http://localhost:8081/tasks \
  -H "Content-Type: application/json" \
  -d '{"title": "Тестовая задача"}'
```
